# SymphonyESP
## Authors
 - Daniel Florek
 - Maciej Pollok

## Description
Modular, ESP32-powered Wi-Fi & Bluetooth audio node with MultiRoom and spatial surround support. Includes a dedicated PC control application.

## Key features
 - Wi-Fi & Bluetooth Audio Streaming
 - MultiRoom Synchronized Playback
 - Spatial Surrond Configuration
 - SSDP Dynamic Node Discovery
 - Dedicated PC Control Application
