state machine:
IDLE
CONFIGURING
BUFFERING
PLAYING
SHUTDOWN

commands:
SHUTDOWN - command for changing sources, also before configuration state
PLAY - sets target playing = true
STOP - clears target playing = false
CONFIGURE - sends format, sample rate from SRC!!!

events:
STOPPED - is in IDLE, CONFIGURING, does not have parameters set for decoder, i2s
READY - parameters are set (format, i2s), ie. mp3, 44.1kHz
ERROR
